## Instalación / Installation / Instalação
1. Descarga el ZIP / Download the ZIP / Baixe o ZIP.
2. QGIS > Complementos > Administrar e instalar > *Instalar a partir de ZIP* / Plugins > Manage and Install > *Install from ZIP*.
3. Activa el complemento / Enable the plugin. Gratis: 20 descargas nuevas al mes por complemento; Pro: ilimitado (licencia en el sitio web).

## Naturaleza del servicio / Nature of the service / Natureza do serviço
**ES:** GEOCARTA ofrece el *proceso* (descarga automatizada en QGIS y georreferenciación, para ahorrar tiempo de preparación antes del análisis). **No vende ni distribuye los mapas ni los datos**: provienen directamente de la fuente oficial de cada país y conservan su licencia y atribución. Herramienta independiente, no oficial ni respaldada por ninguna institución.
